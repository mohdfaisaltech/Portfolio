# Cooling Expert — Static Website

Production-ready static HTML/CSS/vanilla JS site for GitHub Pages project hosting at `https://mohdfaisaltech.github.io/Portfolio/`.

## Deployment in 5 steps
1. Create or open the `mohdfaisaltech/Portfolio` repository and upload the contents of this ZIP so `index.html` is at the repository root.
2. Commit the files to the `main` branch.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)** and save.
5. Wait for GitHub Pages to publish, then open `https://mohdfaisaltech.github.io/Portfolio/`.

## URL configuration
The site base URL is repeated in the generated canonical, Open Graph, sitemap, robots and llms files as `https://mohdfaisaltech.github.io/Portfolio/`. If moved to a custom domain, find and replace that exact base URL with the final HTTPS origin while keeping page paths relative in HTML.
